## 🚀 Run Locally

This is a static HTML website. No Node.js installation or build process is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/naresh9448/Naresh-Wedding.git
   ```

2. Open the project folder:

   ```bash
   cd Naresh-Wedding
   ```

3. Open `index.html` in your browser.

You can also open the folder in Visual Studio Code and use the Live Server extension for local preview.

## 🌍 Deploy with GitHub Pages

1. Push the website files to the `main` branch of the `naresh9448/Naresh-Wedding` repository.
2. Open the repository on GitHub.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` folder, then save.
6. After GitHub Pages finishes deploying, visit:

   [https://naresh9448.github.io/Naresh-Wedding/](https://naresh9448.github.io/Naresh-Wedding/)

Keep `index.html` and all referenced image, audio, video, font, and other asset files in the paths expected by the HTML. If you replace or move an asset, update its path in `index.html` as well.

## 🛠️ Customize

- Update names, dates, event details, and venue links in the page configuration inside `index.html`.
- Replace photos, music, or other media only after checking the corresponding file paths in the HTML.
- Keep the Open Graph and Twitter metadata aligned with the live website URL so link previews show the correct wedding details.
- For a custom social preview image, add `og-image.jpg` (recommended dimensions: 1200 × 630 px) to the repository root. Update the metadata image path in `index.html` if needed so it points to the correct file under `/Naresh-Wedding/`.
